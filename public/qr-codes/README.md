# 支付二维码图片说明

## 📁 文件位置

请将你的收款二维码图片放在此目录下：

- **微信收款二维码**: `wechat-qr.png`
- **支付宝收款二维码**: `alipay-qr.png`

## 📐 图片要求

### 推荐尺寸
- **最小尺寸**: 256x256 像素
- **推荐尺寸**: 512x512 像素
- **最大尺寸**: 1024x1024 像素

### 格式要求
- **格式**: PNG 或 JPG
- **背景**: 白色背景（推荐）
- **质量**: 清晰，二维码边缘清晰可见

## 🔧 如何获取收款二维码

### 微信收款二维码
1. 打开微信 → 我 → 服务 → 收付款
2. 点击"二维码收款"
3. 保存或截图二维码
4. 将图片命名为 `wechat-qr.png` 并放在此目录

### 支付宝收款二维码
1. 打开支付宝 → 首页 → 收钱
2. 点击"保存图片"或截图
3. 将图片命名为 `alipay-qr.png` 并放在此目录

## ⚠️ 注意事项

- 确保二维码清晰可见
- 二维码中心不要有遮挡
- 建议使用白色背景
- 图片文件大小建议控制在 500KB 以内

## 🎨 图片优化建议

如果需要优化图片：
1. 使用图片压缩工具（如 TinyPNG）
2. 确保二维码清晰度
3. 保持白色背景

## 📝 占位符说明

如果图片不存在，页面会显示占位符提示。上传图片后刷新页面即可看到二维码。
